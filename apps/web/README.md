# TradeBridge — Web (Next.js)

Frontend for the TradeBridge platform. See the root [`RUNNING_LOCALLY.md`](../../RUNNING_LOCALLY.md) for full setup/run instructions and demo login credentials.

Quick start (after the API is running — see root docs):

```bash
npm install
cp .env.example .env.local
npm run dev
```

Then open http://localhost:3000.
